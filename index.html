Travel Access Scanner

Capture one image containing credit cards, boarding passes and access QR/barcodes. The app extracts text, decodes boarding-pass QR/PDF417/Aztec where the browser supports it, classifies items, and reads only the first 8 digits from selected card images.

For poor OCR on card numbers: draw a box around one card, then tap Analyze selected area. The app keeps only the first 8 digits and masks the rest.
